    실습 4-2. 필드, 보드 뷰, 자동화¶

    이번 실습에서 할 것

    • 우선순위(단일 선택)와 스프린트(반복) 필드를 만들고 이슈마다 값을 정합니다.
    • 보드 뷰, 그룹 묶기, 로드맵 뷰를 만들어 같은 데이터를 다른 모양으로 봅니다.
    • 자동화(Workflows)를 켜고, 이슈를 닫으면 보드에서 Done으로 옮겨지는 것을 확인합니다.

    소요 시간 약 8분 실습 장소 개인 프로젝트 내 연습 보드 (개인 연습 리포지토리 lunch-practice의 이슈) 관련 교안 4교시 교안

    준비¶

    • 실습 4-1에서 만든 내 연습 보드를 엽니다. 이슈가 3개 이상 담겨 있어야 합니다.
    • lunch-practice의 Issues 탭도 다른 브라우저 탭에 열어 둡니다. STEP 5에서 이슈를 하나 닫습니다.

    STEP 1. 우선순위 필드 만들기 (Single select)¶

    1. 표 머리 맨 오른쪽 + 버튼을 클릭합니다.
    2. + New field(새 필드)를 클릭합니다.

    3. Field name(필드 이름)에 아래 이름을 입력합니다.

      우선순위

    4. Field type(필드 종류)에서 Single select(단일 선택)를 고릅니다.

    5. Options(선택지) 칸에 상, 중, 하를 하나씩 입력합니다. 하나 입력하고 Add option 또는 Enter를 누르면 다음 칸이 생깁니다.
    6. Save(저장)를 클릭합니다.

    확인: 표 머리에 우선순위 칸이 새로 생기면 성공입니다.

    STEP 2. 스프린트 필드 만들기 (Iteration)¶

    1. 표 머리 맨 오른쪽 + → + New field를 클릭합니다.

    2. Field name에 아래 이름을 입력합니다.

      스프린트

    3. Field type에서 Iteration(반복)을 고릅니다.

    4. Starts on(시작일)은 오늘 날짜, Duration(기간)은 1 weeks로 둡니다.
    5. Save를 클릭합니다.

    확인: 표 머리에 스프린트 칸이 생기고, 칸을 누르면 Iteration 1, Iteration 2처럼 1주 단위 기간이 보이면 성공입니다.

    스프린트 이름이 Iteration 1로 나옵니다

    GitHub가 자동으로 붙이는 이름입니다. 그대로 써도 됩니다. 이름을 바꾸고 싶으면 스프린트 필드 머리 → ... → Field settings에서 각 기간 이름을 스프린트 1, 스프린트 2로 고칠 수 있습니다.

    STEP 3. 이슈마다 값 정하기¶

    엑셀 칸을 채우듯이 이슈마다 값을 정합니다.

    1. 첫 번째 이슈 줄의 우선순위 칸을 클릭하고 상을 고릅니다.
    2. 나머지 이슈도 상, 중, 하 중 하나씩 정합니다. 적어도 하나는 상, 하나는 중이 되게 하세요.
    3. 스프린트 칸을 클릭하고, 상인 이슈는 첫 번째 기간, 나머지는 두 번째 기간을 고릅니다.

    확인: 모든 이슈 줄에 우선순위와 스프린트 값이 채워져 있으면 성공입니다.

    STEP 4. 보드 뷰 만들기¶

    같은 이슈를 칸반 보드 모양으로 봅니다.

    1. 위쪽 뷰 탭(지금은 View 1) 오른쪽의 + New view(새 뷰)를 클릭합니다.
      • 또는 뷰 탭 이름 옆 ▼를 눌러 Layout(레이아웃)에서 바꿀 수도 있습니다. 이 방법은 지금 보던 표 뷰 자체가 보드로 바뀝니다.
    2. 새 뷰가 열리면 뷰 탭의 ▼ → Layout → Board(보드)를 클릭합니다.
    3. 화면에 Todo, In Progress, Done 세 칸이 보입니다. 보드 칸은 Status 필드 값으로 나뉩니다.
      • 담긴 카드가 No Status 칸에 있다면 카드를 Todo 칸으로 끌어 옮기세요.
    4. Todo 칸의 카드 하나를 마우스로 끌어서 In Progress 칸에 놓습니다.

    5. 뷰 탭 이름을 더블클릭해서 아래 이름으로 바꾸고 Enter를 누릅니다.

      진행 보드

    6. 뷰 탭 옆에 Save(저장) 버튼이 보이면 클릭합니다. 뷰 설정을 바꾸면 저장해야 다음에 열어도 그대로입니다.

    확인: 진행 보드 탭에 세 칸이 보이고, 옮긴 카드가 In Progress 칸에 있으면 성공입니다.

    STEP 5. 표에서 우선순위로 묶기 (Group by)¶

    1. 첫 번째 표 뷰 탭(View 1)을 클릭합니다.
    2. 뷰 탭 이름 옆 ▼를 클릭합니다.
    3. Group by(묶기) → 우선순위를 클릭합니다.
    4. Save를 클릭합니다.

    확인: 표가 상, 중, 하 묶음으로 나뉘어 보이면 성공입니다. 그리고 STEP 4에서 In Progress로 옮긴 이슈의 Status 칸이 표에서도 In Progress로 보이는지 확인하세요.

    STEP 6. 로드맵 뷰 살짝 보기¶

    1. + New view를 클릭합니다.
    2. 새 뷰 탭의 ▼ → Layout → Roadmap(로드맵)을 클릭합니다.
    3. 오른쪽 위 Date fields(날짜 필드) 메뉴에서 스프린트를 고릅니다. (처음부터 스프린트로 되어 있으면 그대로 둡니다.)
    4. 이슈들이 시간축 위에 1주 길이 막대로 나타납니다.

    확인: 상 이슈는 첫째 주, 나머지는 둘째 주에 막대가 그려지면 성공입니다. 로드맵은 저장하지 않고 넘어가도 됩니다.

    STEP 7. 자동화 켜고 확인하기¶

    1. 프로젝트 오른쪽 위 ... 메뉴를 클릭합니다.
    2. Workflows(자동화)를 클릭합니다.

    3. 왼쪽 목록에서 아래 세 가지를 하나씩 눌러 상태를 봅니다. 꺼져 있으면 오른쪽 위 Edit → 설정 확인 → Save and turn on workflow를 클릭해 켭니다.

      자동화 확인할 설정
      Item closed Set value: Status → Done
      Pull request merged Set value: Status → Done
      Item added to project Set value: Status → Todo

    4. 왼쪽 위 프로젝트 이름을 눌러 프로젝트로 돌아갑니다.

    5. 다른 탭의 lunch-practice → Issues에서 Todo나 In Progress에 있던 이슈 하나를 엽니다.
    6. 이슈 아래쪽 Close issue(이슈 닫기)를 클릭합니다.
    7. 프로젝트 탭으로 돌아가 진행 보드 뷰를 봅니다. 바로 안 바뀌면 몇 초 기다리거나 새로고침합니다.

    확인: 닫은 이슈 카드가 손대지 않았는데도 Done 칸으로 옮겨져 있으면 성공입니다.

    왜 이렇게 하나요?

    오후 팀 실습에서는 PR에 Closes #번호를 써서 병합합니다. 병합하면 이슈가 자동으로 닫히고, 이슈가 닫히면 이 자동화가 보드를 Done으로 옮깁니다. 누구도 보드를 손으로 정리하지 않아도 진행 상황이 맞게 됩니다. 교안의 #번호 연결을 다시 보세요.

    STEP 8. 세 뷰가 같은 데이터인지 확인하기¶

    1. 진행 보드에서 아무 카드나 클릭해 오른쪽 패널을 엽니다.
    2. 패널에서 우선순위 값을 다른 값으로 바꿉니다.
    3. 첫 번째 표 뷰 탭으로 갑니다.

    확인: 표에서 그 이슈가 바뀐 우선순위 묶음으로 옮겨져 있으면 성공입니다. 표, 보드, 로드맵은 같은 데이터를 다른 모양으로 보여 줄 뿐입니다.

    성공하면¶

    • 우선순위(상, 중, 하)와 스프린트(1주 반복) 필드가 있다
    • 모든 이슈에 우선순위와 스프린트 값이 있다
    • 진행 보드 보드 뷰에 Todo, In Progress, Done 칸이 있다
    • 표 뷰가 우선순위로 묶여 있다
    • 자동화 Item closed, Pull request merged, Item added to project가 켜져 있다
    • 닫은 이슈가 보드에서 자동으로 Done으로 갔다

    막히면¶

    표 머리 맨 오른쪽에 + 버튼이 보이지 않습니다

    표가 화면보다 넓어서 오른쪽이 잘린 것입니다. 표를 오른쪽 끝까지 가로로 스크롤하세요. 또는 키보드에서 Ctrl+K(Mac은 Cmd+K)를 누르고 field를 입력해 Create new field를 고를 수도 있습니다.

    보드에 칸이 No Status 하나뿐입니다

    Status 필드 값이 비어 있어서 그렇습니다. 카드를 하나씩 Todo 칸으로 끌어 옮기세요. 칸이 아예 안 보이면 뷰 탭 ▼ → Column by → Status를 고릅니다.

    뷰를 바꿨는데 새로고침하니 원래대로 돌아갔습니다

    뷰 설정을 바꾼 뒤 Save를 누르지 않았습니다. 뷰 탭 옆에 파란 점이나 Save 버튼이 보이면 저장되지 않은 상태입니다.

    이슈를 닫았는데 보드에서 Done으로 가지 않습니다

    ... → Workflows → Item closed가 켜져 있는지 확인하세요. 켜져 있다면 페이지를 새로고침합니다. 자동화를 켜기 전에 닫은 이슈는 옮겨지지 않으니, 이슈를 Reopen issue로 다시 연 뒤 한 번 더 닫아 보세요.

    로드맵에 막대가 보이지 않습니다

    Date fields가 스프린트로 되어 있는지, 이슈에 스프린트 값이 있는지 확인합니다. 화면 위 Today 버튼을 누르면 오늘 날짜 근처로 이동합니다.

    다음 실습으로 넘어가기 전에¶

    • 내 연습 보드는 지우지 않습니다. 확인 퀴즈의 혼자 해보기에서 다시 씁니다.
    • 닫은 이슈는 그대로 두어도 됩니다.
    • 이제부터는 팀 실습입니다. 강사가 팀 번호와 역할을 알려 줍니다.
