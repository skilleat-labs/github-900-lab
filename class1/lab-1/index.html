    실습 1-1. 내 첫 리포지토리 만들기¶

    이번 실습에서 할 것

    • 내 프로필(github.com/내아이디)에서 시작해 빈 리포지토리 my-first-repo를 직접 만듭니다.
    • README를 웹에서 고치고 Commit changes를 눌러 첫 커밋을 남깁니다.
    • 커밋 수가 1에서 2로 늘고, 이력에 내 커밋이 쌓이는 것을 확인합니다.

    소요 시간 약 6분 실습 장소 내 첫 리포지토리 my-first-repo 관련 교안 1교시 교안

    준비¶

    • github.com에 로그인되어 있어야 합니다. 오른쪽 위에 내 프로필 사진이 보이면 로그인된 상태입니다.
    • 브라우저 탭 하나만 있으면 됩니다. 설치할 프로그램은 없습니다.
    • 이 실습은 "리포지토리를 만들고, 고치고, 커밋하면 기록이 남는다"를 처음 해 보는 연습입니다. 오늘 하루 계속 쓰는 연습 리포지토리 lunch-practice는 다음 실습 1-2에서 따로 만듭니다.

    STEP 1. 내 프로필 열기¶

    교안에서 본 것처럼 github.com/내아이디가 내 공간입니다. 먼저 그 공간으로 갑니다.

    1. 화면 오른쪽 위의 내 프로필 사진을 클릭합니다.
    2. 펼쳐진 메뉴에서 Profile(또는 Your profile)을 클릭합니다.
    3. 브라우저 주소창을 봅니다. https://github.com/<내아이디> 모양입니다.
    4. 프로필 이름 아래 탭 줄에서 Repositories를 클릭합니다.

    확인: 주소창이 github.com/<내아이디>?tab=repositories이고, 처음 가입한 계정이라면 리포지토리 목록이 비어 있습니다. 이 실습을 마치면 여기에 my-first-repo가 생깁니다.

    STEP 2. 빈 리포지토리 만들기¶

    1. Repositories 목록 오른쪽 위의 초록색 New 버튼을 클릭합니다. (화면 오른쪽 위 + → New repository를 눌러도 같은 화면이 열립니다.)

    2. "Create a new repository" 화면이 열립니다. 아래 표대로 입력합니다.

      항목 입력하거나 고를 값 설명
      Owner 내 GitHub 아이디 조직 이름이 보여도 고르지 않습니다
      Repository name my-first-repo 아래 코드 블록을 복사해서 붙여 넣으세요
      Description 비워 둠 선택 항목입니다
      공개 범위 (Choose visibility) Public 오늘 실습은 모두 공개 리포지토리로 합니다
      Add README On으로 켬 화면에 따라 Add a README file 체크박스로 보입니다. 체크합니다 
      my-first-repo

    3. Repository name 칸 아래에 초록색으로 my-first-repo is available.이 보이는지 확인합니다.

    4. 화면 맨 아래 초록색 Create repository(리포지토리 만들기) 버튼을 클릭합니다.

    확인: 화면 위쪽에 내아이디 / my-first-repo가 보이고, 주소창이 https://github.com/<내아이디>/my-first-repo입니다. 내 공간(/내아이디) 뒤에 리포지토리 이름(/my-first-repo)이 붙은 주소입니다.

    Add README를 왜 켜나요?

    README를 켜지 않으면 파일이 하나도 없는 정말 빈 리포지토리가 생기고, 첫 화면에 명령어 안내만 잔뜩 보입니다. README를 켜면 GitHub가 README.md 파일 하나를 넣고 첫 커밋을 대신 만들어 줍니다. 그래서 바로 파일을 열어 고칠 수 있습니다.

    STEP 3. 첫 화면에서 커밋 1개 확인하기¶

    1. 파일 목록에 README.md 하나만 있는지 봅니다.
    2. 파일 목록 바로 위 회색 줄을 봅니다. 왼쪽에는 내 아이디와 Initial commit이라는 메시지가, 오른쪽 끝에는 시계 아이콘과 함께 1 Commit이 보입니다.
    3. 파일 목록 아래에 README 내용이 펼쳐져 있습니다. 지금은 my-first-repo라는 제목 한 줄뿐입니다.

    확인: 1 Commit입니다. 리포지토리를 만든 순간 README를 넣은 커밋 1개가 생겼습니다. 작성자는 나, 메시지는 GitHub가 넣은 Initial commit입니다.

    STEP 4. README 고치고 커밋하기¶

    1. 파일 목록에서 README.md를 클릭합니다.
    2. 파일 내용 위쪽 오른편의 연필 아이콘(마우스를 올리면 Edit this file)을 클릭합니다.

    3. 편집 칸이 열립니다. 첫 줄 # my-first-repo 끝을 클릭하고 Enter 를 두 번 누른 뒤, 아래 문장을 입력합니다.

      GitHub 첫 연습입니다. 고치고 커밋하면 기록이 남는지 확인합니다.

    4. 아직 저장된 게 아닙니다. 화면 오른쪽 위의 초록색 Commit changes...(변경 저장) 버튼을 클릭합니다.

    5. Commit changes 대화상자가 열립니다. Commit message 칸의 기본값 Update README.md를 지우고 아래처럼 씁니다.

      README에 소개 한 줄 추가

    6. 아래 선택지가 Commit directly to the main branch인지 확인하고, 초록색 Commit changes 버튼을 클릭합니다.

    확인: README.md 화면으로 돌아오고, 내용 위 회색 줄에 내 아이디, README에 소개 한 줄 추가, now(방금)가 보입니다.

    Commit changes를 누르지 않고 창을 닫으면

    편집 칸에서 고친 내용은 Commit changes를 누르기 전까지 어디에도 저장되지 않습니다. 교안의 "Commit changes가 저장 버튼"이 바로 이 뜻입니다.

    STEP 5. 커밋이 쌓인 것 보기¶

    1. 위쪽 리포지토리 이름 my-first-repo를 클릭해 첫 화면으로 돌아갑니다.
    2. 회색 줄 오른쪽 끝이 2 Commits로 바뀌었는지 봅니다. 클릭합니다.
    3. 커밋 목록이 최신순으로 보입니다. 맨 위 README에 소개 한 줄 추가 메시지를 클릭합니다.
    4. 바뀐 내용이 보입니다. 내가 넣은 문장이 앞에 +가 붙은 초록 줄로 보입니다.

    확인: 커밋 목록에 README에 소개 한 줄 추가(위)와 Initial commit(아래) 2개가 있고, 내 커밋을 열면 추가한 문장이 초록 줄로 보입니다.

    순서 커밋 메시지 누가 만들었나
    1 (위, 최신) README에 소개 한 줄 추가 내가 STEP 4에서
    2 (아래, 처음) Initial commit 리포지토리를 만들 때 GitHub가

    핵심

    파일을 고치고 Commit changes를 누를 때마다 커밋이 하나씩 쌓입니다. 누가, 언제, 무엇을, 왜(메시지) 바꿨는지가 함께 남습니다. 이력 화면은 실습 1-3에서 더 자세히 봅니다.

    성공하면¶

    • https://github.com/<내아이디>/my-first-repo 리포지토리가 있습니다. Public입니다.
    • README에 내가 넣은 소개 문장이 보입니다.
    • 첫 화면 커밋 수가 2 Commits입니다.
    • 커밋 목록 맨 위가 README에 소개 한 줄 추가입니다.

    막히면¶

    New 버튼이 안 보입니다

    다른 사람의 프로필이나 조직 화면에 있는 경우입니다. 오른쪽 위 프로필 사진 → Profile로 내 프로필에 들어갔는지 확인합니다. 또는 화면 오른쪽 위 + → New repository를 누릅니다.

    The repository my-first-repo already exists on this account 라고 나옵니다

    예전에 같은 이름으로 만든 리포지토리가 있습니다. 이름 뒤에 숫자를 붙여 my-first-repo-2로 만들고 진행합니다.

    첫 화면에 파일이 없고 Quick setup 명령어만 보입니다

    STEP 2에서 Add README를 켜지 않은 경우입니다. 화면의 creating a new file 또는 README 링크를 눌러 README.md를 만들고 커밋하면 됩니다. 이 경우 STEP 4까지 마치면 커밋 수가 2가 아니라 1일 수 있습니다. 괜찮습니다.

    Commit changes 버튼이 회색이라 눌리지 않습니다

    아무것도 고치지 않은 상태입니다. 편집 칸에 문장이 들어갔는지 확인합니다.

    다음 실습으로 넘어가기 전에¶

    • my-first-repo는 1교시 연습용입니다. 이후 교시에서는 쓰지 않지만 지우지 않아도 됩니다.
    • 다음 실습 1-2에서 오늘 하루 계속 쓸 연습 리포지토리 lunch-practice를 만듭니다.
