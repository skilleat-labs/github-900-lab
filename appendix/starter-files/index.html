    docs/00_현업요청.md 
    # 현업 요청: 점심 메뉴 추천 서비스

- 보낸 사람: 경영지원팀 박지은 과장
- 받는 사람: 사내 서비스 기획팀
- 제목: 점심 메뉴 정하는 시간 좀 줄여 주세요

---

안녕하세요, 경영지원팀 박지은입니다.

요즘 팀마다 점심 메뉴를 정하는 데 시간이 너무 오래 걸립니다.
11시 40분쯤 메신저 단톡방에 "오늘 뭐 먹지?"가 올라오면, 의견이 모이고 정리되는 데 보통 15~20분이 걸립니다.
결국 12시가 넘어서 출발하고, 인기 있는 식당은 자리가 없어서 다시 고민하는 일이 반복됩니다.

그래서 간단한 점심 메뉴 추천 서비스가 있으면 좋겠습니다. 바라는 점을 적어 보면 아래와 같습니다.

1. 회사 근처 식당 메뉴를 한눈에 보고 싶습니다. 메뉴 이름, 종류(한식, 중식 등), 가격, 회사에서 걸리는 거리 정도면 충분합니다.
2. 오늘 쓸 수 있는 예산을 넣으면 그 안에서 고를 수 있는 메뉴만 보였으면 좋겠습니다.
3. 너무 멀리 가기 싫은 날이 많습니다. 가까운 곳만 볼 수 있으면 좋겠습니다.
4. 도저히 못 고르겠을 때는 버튼 하나로 아무거나 하나 골라 주면 좋겠습니다.
5. 혼자 먹는 날도 있습니다. 혼밥하기 편한 곳인지 표시가 있으면 좋겠습니다.
6. 팀원들이 후보 중에 투표해서 정하는 기능도 있으면 재미있을 것 같습니다.

급한 순서로 따지면 1, 2번이 제일 급하고, 나머지는 천천히 해도 됩니다.
자세한 이야기는 킥오프 회의 때 나누면 좋겠습니다.

감사합니다.
박지은 드림
    docs/01_킥오프_회의록.md 
    # 킥오프 회의록: 점심 메뉴 추천 서비스

- 일시: 월요일 오후 2시, 3층 소회의실
- 참석: 박지은(경영지원팀, 요청자), 이민호(영업1팀), 최수진(개발팀), 정다은(기획팀)
- 작성: 정다은

---

## 1. 서비스 목적

- 박지은: 점심 메뉴 정하는 데 15~20분씩 쓰는 걸 줄이고 싶다. 5분 안에 정하는 게 목표.
- 정다은: 그럼 성공 기준은 "메뉴 결정 시간 5분 이내"로 잡으면 되겠다.

## 2. 메뉴 정보

- 박지은: 메뉴 이름, 종류, 가격, 거리만 있으면 된다.
- 이민호: 사진도 있으면 좋겠는데, 없어도 괜찮다.
- 최수진: 메뉴 데이터는 처음엔 우리가 직접 정리해서 넣는 걸로 하자. 식당 사이트에서 자동으로 가져오는 건 어렵다.
- 정다은: 식당 정보 자동 수집은 이번에는 안 해도 되는 걸로 정리.

## 3. 가격

- 박지은: 점심값은 만 원 이하만 보여 주면 된다. 그 이상은 아무도 안 먹는다.
- 이민호: 그런데 우리 팀은 금요일에 회식 겸 점심을 자주 해서, 만 원 넘는 메뉴도 추천해 줬으면 한다.
- (결론 못 냄. 다음에 다시 이야기하기로 함)

## 4. 추천 방식

- 박지은: 못 고를 때는 그냥 하나만 딱 골라 주면 좋겠다.
- 이민호: 하나만 골라 주면 다들 마음에 안 든다고 할 거다. 후보를 서너 개 보여 주고 팀원들이 투표하는 게 낫다.
- 최수진: 투표는 사람마다 로그인을 해야 해서 일이 커진다.
- 정다은: 로그인 기능은 이번에는 안 해도 되는 걸로 하자.
- (추천을 하나로 할지 여러 개로 할지는 결론 못 냄)

## 5. 거리

- 박지은: 걸어서 10분 안쪽이면 된다.
- 최수진: 거리는 미터로 넣을지 분으로 넣을지 정해야 한다. 일단 미터로 넣자.
- 이민호: 비 오는 날에는 가까운 데가 더 중요하다.

## 6. 기타

- 이민호: 혼밥 가능한지 표시는 꼭 있었으면 좋겠다.
- 박지은: 웹페이지 하나로 열리면 충분하다. 앱은 필요 없다.
- 정다은: 첫 출시는 최대한 작게 하고, 써 보고 나서 늘리자.

## 결정 사항

1. 메뉴 데이터는 직접 정리해서 넣는다.
2. 웹페이지 하나로 만든다.
3. 식당 정보 자동 수집과 로그인 기능은 이번에는 하지 않는다.
4. 첫 출시는 최대한 작게 한다.

## 결정하지 못한 것

1. 만 원이 넘는 메뉴도 보여 줄지
2. 추천을 하나만 할지, 여러 개 후보를 보여 줄지
    docs/02_현행_업무.md 
    # 현행 업무: 지금은 점심 메뉴를 이렇게 정합니다

## 지금의 흐름

1. 11시 40분쯤 누군가 팀 메신저 단톡방에 "오늘 뭐 먹지?"를 올립니다.
2. 팀원들이 각자 먹고 싶은 메뉴를 하나씩 답합니다.
3. 의견이 갈리면 누군가 메신저 투표를 엽니다.
4. 투표가 끝나면 막내가 식당에 자리가 있는지 전화로 확인합니다.
5. 자리가 없으면 2번으로 돌아갑니다.

## 불편한 점

| 불편한 점 | 자주 나오는 말 |
|---|---|
| 정하는 데 오래 걸림 | "벌써 12시 5분이에요" |
| 가격을 몰라서 다시 물어봄 | "거기 얼마였죠?" |
| 거리를 몰라서 다시 물어봄 | "거기 멀지 않아요?" |
| 늘 가던 곳만 감 | "또 김치찌개요?" |
| 혼자 먹을 곳 찾기 어려움 | "혼자 가도 되는 데 있어요?" |

## 참고: 자주 가는 식당 메모 (막내의 엑셀에서 옮김)

  <script>
    let menus = [];
    const list = document.getElementById("list");
    const won = (n) => n.toLocaleString("ko-KR") + "원";

    function filtered() {
      const b = Number(document.getElementById("budget").value) || Infinity;
      const d = Number(document.getElementById("distance").value) || Infinity;
      return menus.filter((m) => m.price <= b && m.distance <= d);
    }

    function render() {
      const items = filtered();
      if (items.length === 0) { list.innerHTML = '<p class="empty">조건에 맞는 메뉴가 없습니다.</p>'; return; }
      list.innerHTML = items.map((m) => `
        <div class="card">
          <h2>${m.name}</h2>
          <div class="meta">${m.category}  |  ${won(m.price)}  |  ${m.distance}m</div>
          ${m.solo ? '<span class="badge">혼밥 가능</span>' : ""}
          ${m.delivery ? '<span class="badge delivery">배달 가능</span>' : ""}
        </div>`).join("");
    }

    document.getElementById("budget").addEventListener("input", render);
    document.getElementById("distance").addEventListener("input", render);
    document.getElementById("random").addEventListener("click", () => {
      const items = filtered();
      document.getElementById("pick").textContent = items.length
        ? "오늘의 추천: " + items[Math.floor(Math.random() * items.length)].name
        : "조건에 맞는 메뉴가 없습니다.";
    });

    fetch("menus.json").then((r) => r.json()).then((data) => { menus = data; render(); });
  </script>
</body>
</html>

    .github/workflows/check.yml
    name: 메뉴 데이터 검사

on:
  pull_request:
  workflow_dispatch:

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: node scripts/check-menus.js
    .github/workflows/pages.yml
    name: 웹페이지 배포

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  deploy:
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with:
          path: site
      - id: deployment
        uses: actions/deploy-pages@v4
    scripts/check-menus.js 
    // 메뉴 데이터 검사: site/menus.json의 형식과 필수 항목을 확인한다.
// PR이 열리면 GitHub Actions(.github/workflows/check.yml)가 이 파일을 실행한다.
const fs = require("fs");

const FILE = "site/menus.json";
const errors = [];

let menus;
try {
  menus = JSON.parse(fs.readFileSync(FILE, "utf8"));
} catch (e) {
  console.error(`[실패] ${FILE}이 올바른 JSON 형식이 아닙니다.`);
  console.error(`       쉼표, 따옴표, 괄호가 빠지지 않았는지 확인하세요.`);
  console.error(`       자세한 내용: ${e.message}`);
  process.exit(1);
}

if (!Array.isArray(menus)) {
  console.error(`[실패] ${FILE}은 [ ]로 감싼 목록이어야 합니다.`);
  process.exit(1);
}

menus.forEach((m, i) => {
  const where = `${i + 1}번째 메뉴(${m && m.name ? m.name : "이름 없음"})`;
  if (typeof m.name !== "string" || m.name.trim() === "") errors.push(`${where}: name(메뉴 이름)이 없습니다.`);
  if (typeof m.category !== "string" || m.category.trim() === "") errors.push(`${where}: category(종류)가 없습니다.`);
  if (typeof m.price !== "number" || m.price <= 0) errors.push(`${where}: price(가격)는 0보다 큰 숫자여야 합니다.`);
  if (typeof m.distance !== "number" || m.distance < 0) errors.push(`${where}: distance(거리, 미터)는 숫자여야 합니다.`);
  if ("solo" in m && typeof m.solo !== "boolean") errors.push(`${where}: solo(혼밥 가능)는 true 또는 false여야 합니다.`);
  if ("delivery" in m && typeof m.delivery !== "boolean") errors.push(`${where}: delivery(배달 가능)는 true 또는 false여야 합니다.`);
});

const names = menus.map((m) => m.name);
names.forEach((n, i) => { if (names.indexOf(n) !== i) errors.push(`메뉴 이름이 겹칩니다: ${n}`); });

if (errors.length) {
  errors.forEach((e) => console.error("[실패] " + e));
  process.exit(1);
}
console.log(`[통과] 메뉴 ${menus.length}개를 검사했습니다. 문제가 없습니다.`);
