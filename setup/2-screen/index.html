    2. GitHub 화면 둘러보기¶

    실습 중에 가장 자주 쓰는 화면 위치를 미리 익혀 둡니다. 리포지토리 하나를 열면 위쪽에 탭이 줄지어 있습니다.

    로그인하면 처음 보이는 화면 (대시보드)¶

    github.com에 로그인하면 대시보드가 열립니다. 왼쪽 위 GitHub 로고(고양이)를 누르면 언제든 이 화면으로 돌아옵니다.

    위치 이름 하는 일
    왼쪽 Top repositories 내 리포지토리 목록. 처음 가입하면 비어 있습니다
    가운데 위 Ask anything 입력 칸 AI 도우미 Copilot. 이 과정에서는 쓰지 않습니다
    가운데 아래 Pull requests, Issues 나에게 온 PR과 이슈
    오른쪽 위 +, 종 모양, 프로필 사진 새로 만들기, 알림, 내 프로필과 설정

    내 프로필은 내 공간입니다¶

    가입할 때 정한 아이디가 내 공간의 주소가 됩니다.

    • github.com/<내 아이디>: 내 프로필. 오른쪽 위 프로필 사진 → Your profile로도 열립니다. Repositories 탭에 내가 만든 리포지토리가 모입니다.
    • github.com/<내 아이디>/<리포지토리 이름>: 내 리포지토리

    리포지토리 화면의 탭¶

    탭 뜻 이 과정에서 쓰는 때
    Code 파일과 폴더, README 1교시부터 계속
    Issues 할 일, 요구사항, 질문 카드 2교시, 5~6교시
    Pull requests 변경 제안과 리뷰 3교시, 6교시
    Actions 자동으로 돌아가는 작업 (검사, 배포) 1교시(배포), 3교시, 6교시
    Projects 연결된 기획판 4~6교시
    Settings 리포지토리 설정 (소유자만 보임) 1교시(Pages), 3교시(초대), 7교시(보호 규칙)

    Settings 탭이 안 보여요

    Settings는 리포지토리 소유자(또는 관리자 권한이 있는 사람)에게만 보입니다. 팀 리포지토리에서는 리포지토리를 만든 PO만 볼 수 있습니다.

    Code 탭에서 자주 누르는 곳¶

    ┌───────────────────────────────────────────────────────────┐
│ [main ▼]  1 Branch  0 Tags        [Go to file] [Add file ▼] [<> Code ▼] │  ← 분기 선택, 파일 추가
├───────────────────────────────────────────────────────────┤
│ 아이디  최근 커밋 메시지                    a1b2c3d    3 Commits │  ← 커밋 수를 누르면 이력
│ docs/                                                         │
│ site/                                                         │
│ README.md                                                     │
├───────────────────────────────────────────────────────────┤
│ README 내용이 여기에 보입니다                                    │
└───────────────────────────────────────────────────────────┘
    위치 하는 일
    main ▼ (분기 드롭다운) 분기를 고르거나 새 분기를 만듭니다 (3교시)
    Add file ▼ 새 파일 만들기(Create new file), 파일 올리기(Upload files)
    N Commits 커밋 이력 목록 (1교시)
    파일 이름 클릭 → 연필 아이콘 파일 고치기
    파일 화면 → History 그 파일의 변경 이력
    파일 화면 → Blame 줄마다 누가 언제 바꿨는지 (3교시)

    오른쪽 위 공통 메뉴¶

    위치 하는 일
    종 모양(알림) 멘션, 리뷰 요청, 초대 알림
    + ▼ 새 리포지토리, 새 이슈 만들기
    프로필 사진 내 프로필, Your repositories, Your projects, Settings(계정 설정, 7교시 2단계 인증)

    주소 읽는 법¶

    리포지토리 주소는 github.com/<소유자 아이디>/<리포지토리 이름> 입니다.

    주소 뜻
    github.com/kim-minho/lunch-practice kim-minho의 lunch-practice 리포지토리
    .../issues/3 3번 이슈
    .../pull/5 5번 PR
    .../commit/a1b2c3d a1b2c3d 커밋
    .../blob/main/site/menus.json main 분기의 menus.json 파일
    .../compare/v1.0...v1.1 v1.0과 v1.1 사이의 변경 (6교시)

    이슈와 PR은 같은 번호 체계를 씁니다. 1번 이슈를 만들고 PR을 열면 그 PR은 2번이 됩니다.
