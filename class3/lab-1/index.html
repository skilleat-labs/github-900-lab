    실습 3-1. 짝꿍 초대하기¶

    이번 실습에서 할 것

    • 옆 사람과 짝을 짓고 GitHub 아이디를 서로 알려 줍니다.
    • 짝꿍을 내 lunch-practice 리포지토리의 Collaborator(공동 작업자)로 초대합니다.
    • 짝꿍이 보낸 초대를 수락해, 서로의 리포지토리에서 리뷰할 수 있는 상태를 만듭니다.

    소요 시간 약 3분 실습 장소 개인 연습 리포지토리 lunch-practice 관련 교안 3교시 교안

    준비¶

    • 1~2교시에 만든 내 리포지토리 https://github.com/<내 아이디>/lunch-practice를 브라우저에 열어 둡니다.
    • 옆자리 사람과 짝을 짓습니다.

    짝이 맞지 않을 때

    • 전체 인원이 홀수라서 한 명이 남으면 3인 짝을 만듭니다. 세 사람은 각자 나머지 두 사람을 모두 초대합니다. 3-2에서 Reviewers를 지정할 때도 두 사람 중 한 명을 고르면 됩니다.
    • 주변에 짝이 될 사람이 없으면 손을 들어 주세요. 강사 계정을 짝꿍으로 초대하고, 강사가 리뷰를 해 드립니다.

    STEP 1. GitHub 아이디 교환하기¶

    초대하려면 짝꿍의 GitHub 아이디(username)를 정확히 알아야 합니다. 이메일이나 표시 이름이 아니라 아이디입니다.

    1. github.com 오른쪽 위 프로필 사진을 클릭합니다.
    2. 메뉴 맨 위 굵은 글씨 아래에 보이는 회색 글씨가 내 아이디입니다. 주소창의 https://github.com/<아이디>로도 확인할 수 있습니다.
    3. 짝꿍에게 내 아이디를 알려 주고, 짝꿍의 아이디를 받아 적습니다.
    내 아이디:
짝꿍 아이디:

    확인: 짝꿍의 아이디를 철자 그대로 적어 두었습니다.

    STEP 2. 짝꿍을 Collaborator로 초대하기¶

    내 리포지토리는 Public이라 누구나 볼 수는 있지만, 고치려면 권한이 필요합니다. Collaborator로 초대하면 짝꿍이 내 리포지토리에 직접 커밋하고 PR을 리뷰할 수 있습니다.

    1. 내 lunch-practice 리포지토리 위쪽 탭에서 Settings(설정)를 클릭합니다.
    2. 왼쪽 메뉴의 Access 묶음에서 Collaborators(공동 작업자)를 클릭합니다.
      • 비밀번호나 2단계 인증 확인 창이 뜨면 본인이 직접 확인합니다.
    3. Manage access 영역의 초록색 Add people(사람 추가) 버튼을 클릭합니다.
    4. 검색창에 짝꿍의 아이디를 입력합니다.
    5. 아래에 뜨는 목록에서 짝꿍의 프로필 사진과 아이디가 맞는지 확인하고 클릭합니다.
    6. Add <짝꿍 아이디> to this repository(이 리포지토리에 추가) 버튼을 클릭합니다.

    확인: Manage access 목록에 짝꿍 아이디가 보이고, 옆에 Pending Invite(초대 대기 중)라고 표시됩니다.

    왜 이렇게 하나요?

    개인 리포지토리에서는 Collaborator가 받는 권한이 쓰기(Write) 하나뿐입니다. 짝꿍은 파일을 고치고 PR을 리뷰, 병합할 수 있지만 Settings는 볼 수 없습니다. 팀 리포지토리(4교시 이후)에서도 같은 방법으로 팀원을 초대합니다.

    STEP 3. 받은 초대 수락하기¶

    짝꿍이 나를 초대했으면 이제 내가 수락할 차례입니다. 초대는 수락해야 효력이 생깁니다. 아래 세 가지 중 편한 방법 하나를 씁니다.

    1. 주소창에 아래 주소를 입력합니다. <짝꿍 아이디>는 짝꿍의 아이디로 바꿉니다.

      https://github.com/<짝꿍 아이디>/lunch-practice/invitations

    2. 초록색 Accept invitation(초대 수락) 버튼을 클릭합니다.

    1. GitHub 가입 메일함에서 제목이 <짝꿍 아이디> invited you to <짝꿍 아이디>/lunch-practice인 메일을 엽니다.
    2. View invitation(초대 보기) 버튼을 클릭합니다.
    3. Accept invitation 버튼을 클릭합니다.
    1. github.com 오른쪽 위 알림(종 모양 또는 받은 편지함 모양) 아이콘을 클릭합니다.
    2. 짝꿍 리포지토리의 초대 알림을 클릭합니다.
    3. Accept invitation 버튼을 클릭합니다.

    확인: You now have push access to the <짝꿍 아이디>/lunch-practice repository.(이제 이 리포지토리에 쓰기 권한이 있습니다)라는 안내가 보이고, 짝꿍 리포지토리 화면으로 이동합니다.

    STEP 4. 권한이 생겼는지 확인하기¶

    1. 짝꿍 리포지토리 https://github.com/<짝꿍 아이디>/lunch-practice에서 site 폴더 → menus.json 파일을 클릭합니다.
    2. 파일 오른쪽 위 연필 아이콘에 마우스를 올려 봅니다.

    확인: 연필 아이콘의 안내 문구가 Edit this file(이 파일 편집)입니다. 초대를 수락하기 전에는 Fork this repository and edit the file(복사본을 만들어 편집)이라고 나옵니다.

    짝꿍 파일은 고치지 마세요

    확인만 하고 편집 화면은 열지 않습니다. 짝꿍의 main에 실수로 커밋하면 다음 실습이 꼬입니다.

    성공하면¶

    • 내 리포지토리 Settings → Collaborators에 짝꿍 아이디가 있고, Pending Invite 표시가 사라졌다 (짝꿍이 수락함)
    • 짝꿍의 초대를 내가 Accept invitation으로 수락했다
    • 짝꿍 리포지토리의 연필 아이콘 안내가 Edit this file이다

    막히면¶

    Add people 검색창에 짝꿍 아이디를 넣어도 아무도 안 나와요

    아이디 철자가 틀렸거나, 표시 이름(실명)을 넣었을 가능성이 큽니다. 짝꿍에게 프로필 주소 https://github.com/<아이디>를 직접 열어 보게 해서 주소에 있는 아이디를 그대로 받아 오세요.

    Accept invitation 버튼이 없고 404 페이지가 나와요
    • 초대 주소의 아이디가 틀렸거나, 짝꿍이 아직 초대를 보내지 않았습니다. 짝꿍 화면의 Collaborators 목록에 내 아이디가 Pending Invite로 있는지 확인하세요.
    • 다른 계정으로 로그인되어 있을 수 있습니다. 오른쪽 위 프로필 사진을 눌러 내 아이디로 로그인되어 있는지 확인하세요.
    초대 메일이 안 와요

    회사 메일 필터에 걸렸을 수 있습니다. 메일을 기다리지 말고 주소로 바로 가기 방법을 쓰세요.

    연필 아이콘 안내가 여전히 Fork this repository and edit the file이에요

    초대를 아직 수락하지 않았습니다. STEP 3을 다시 하세요. 수락했는데도 그렇다면 페이지를 새로 고침합니다.

    짝꿍 이름 옆에 계속 Pending Invite가 보여요

    짝꿍이 아직 수락하지 않았습니다. 짝꿍에게 STEP 3을 안내해 주세요. 초대는 7일이 지나면 만료되므로, 만료되었다면 목록에서 지우고 다시 Add people을 합니다.

    다음 실습으로 넘어가기 전에¶

    • 짝꿍의 아이디를 3-2, 3-3에서 계속 씁니다. 적어 둔 것을 지우지 마세요.
    • 짝꿍 리포지토리 탭은 닫아도 됩니다. 3-3에서 다시 엽니다.
